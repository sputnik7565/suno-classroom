이제, 내 노래를 들어볼까요?

준비한 가사와 스타일을 수노에 넣고, 어떤 노래가 나오는지 들어봐요.

  1. 수노 Create에서 Custom을 선택해요.
  2. Lyrics에 최종 가사·구조 태그를, Styles에 영어 스타일 문장을 붙여넣어요.
  3. 보컬 곡이므로 Instrumental / 연주곡 전용 설정이 보이면 끄고, Title에 제목을 적어요. 무료 계정에서 사용 가능한 기본 생성 설정을 선택합니다.
  4. 칸을 확인한 뒤 Create를 눌러요. 보이는 버튼 이름·위치는 화면에 따라 달라질 수 있어요.

생성을 기다리는 동안 내 후렴을 한 번 읽고, 마지막 카드의 제출 기록을 채워요. 결과가 나올 때까지 기다리고, 같은 요청을 반복해서 누르지 않아요.

도입과 후렴에서, 내가 고른 소리를 찾아봐요.

여러 결과가 나오면 같은 부분끼리 비교해요. 마음에 드는 곡은 처음부터 끝까지 들어봐요.

한 가지를 바꾸면, 노래도 달라질까요?

가사 발음이 어려우면 한 줄을 줄이고, 후렴이 약하면 Styles에 big sing-along final chorus를 더해요. 남은 생성 크레딧을 확인하고 한 가지만 바꿉니다. 이미 만든 음원이 자동으로 수정되는 것은 아니며, 바꾼 입력으로 새 생성을 요청하는 연습입니다.

생성이 늦거나 크레딧이 없으면?

반복 클릭하거나 수업 중 결제하지 말고 선생님에게 알려요. 준비된 짝과 한 번 생성하거나, 세 입력 칸과 ‘생성 대기 / 미생성’ 이유를 제출합니다. 생성이 끝나지 않아도 가사와 제작 의도는 남길 수 있어요.
